
# Virtual CV

## Project Description

This project is my personal Virtual CV . It was created to present my education, skills, projects, experience, and contact information in an accessible online format.

## Virtual CV

The Virtual CV can be viewed here:
https://mattygoldfish.github.io/Virtual-CV/

## Features

The Virtual CV includes:

- An About Me section
- Education information
- Skills and technical interests
- Project descriptions
- Links to GitHub repositories
- Contact information
- A downloadable PDF version of my CV


## Technologies Used

The website was created using:

- HTML
- CSS
- JavaScript
- Git
- GitHub
- GitHub Pages
